# AGENTS.md

Guide for anyone (human or coding agent) changing this repository. Read it
before editing code, results or documentation.

## What this project is

CongestGym is a Gymnasium environment for reinforcement learning on congested
packet networks. At every step an agent sets a bandwidth weight and a routing
weight for each link, under a total bandwidth budget, and is rewarded for
delivered traffic minus delay, loss and missed deadlines. The repository also
holds six rule-based baselines, a fluid upper bound, scripts that train and
evaluate PPO/SAC, and the committed results reported in the README and in the
project's paper.

## Setup

```
python -m venv .venv
.venv/Scripts/activate            # Windows; on Linux/macOS: source .venv/bin/activate
pip install -e ".[all]"           # exact tested versions: pip install -r requirements.txt -c constraints.txt
```

Scripts import the repo as a package: set `PYTHONPATH=.` (PowerShell:
`$env:PYTHONPATH = "."`) when running anything under `examples/`, `scripts/`
or `qa/`.

## Commands

| Task | Command |
|---|---|
| Tests | `python -m pytest -q` |
| Quick benchmark | `python scripts/run_benchmark.py --quick` |
| Train one agent | `python examples/train_agent.py --algo ppo --timesteps 500000 --seed 0 --load-scale 1.25 --budget 0.6` |
| Full training matrix | `python scripts/run_training_matrix.py --workers 10 --ppo-steps 500000 --sac-steps 100000` (several hours on 12 threads; restartable) |
| Re-evaluate saved models | `python scripts/evaluate_saved.py results/rl/<scenario>` (includes a self-check against `final_eval.csv`) |
| Flow bound | `python scripts/flow_bound.py` |
| Refresh README tables | `python scripts/update_readme_results.py` |
| Demo | `python examples/demo.py --save demo.gif` |

## Rules

1. **Never write a number by hand.** Every figure in the README, notebooks and
   docs must come from a committed result file or log. README tables are
   generated by `scripts/update_readme_results.py` between
   `<!-- RESULTS:...:start/end -->` markers; do not edit inside them.
2. **Seed protocol.** Training seeds 0-4 (plus env ranks), validation seeds
   1000+, test seeds 2000-2009. Make every choice (scenario, hyperparameters,
   baseline constants) on validation seeds. Test seeds are for final
   reporting only, once the choice is recorded.
3. **Fix decision rules before running an experiment**, write them down (see
   `docs/NEXT_EXPERIMENTS.md`, `docs/HEADLINE_SCENARIO.md`), and record any
   deviation openly, as `docs/ABILENE_SCENARIO.md` does.
4. **Changing dynamics invalidates results.** Anything that changes
   `network.py`, `step.py`, `traffic.py`, `trace_traffic.py` or `reward.py`
   behaviour means the benchmark and the affected training runs must be
   rerun, and the version bumped. Keep defaults bit-identical when adding
   options.
5. **Tests guard invariants:** packet-unit conservation, buffer and link
   limits, determinism under a seed, and regressions for past bugs. Add a
   test that fails without your fix for every bug you fix.
6. **Randomness:** the traffic generator uses `default_rng(seed)`; the network
   (tie-breaks, service order) and the `random` baseline use their own
   streams `default_rng([seed, tag])` derived from the same episode seed. Do
   not share streams between components or reseed them mid-episode.
7. **Data:** only derived traces with node ids go in `data/`. Raw captures and
   anything with addresses stay in git-ignored `data/raw/`. Record provenance
   and citations next to each trace.
8. **Git:** work on a branch and open a pull request; CI
   (`.github/workflows/tests.yml`, Python 3.10-3.14 on Linux and Windows) must
   pass. Do not rewrite published history.
9. **Docs in `docs/` are dated records** of how each choice and result was
   made. Do not rewrite their findings; add a dated update at the top or
   bottom when something changes, as the existing banners do.
10. **Report honestly.** State where learned policies lose as clearly as where
   they win, and use paired comparisons on the same test seeds.

## Known limitations (keep them in mind)

The simulator is slotted (one hop per step, no TCP or propagation delay) and
not validated against ns-3; networks are small (9 and 12 nodes); the fluid
bound is loose; on Abilene one step replays one five-minute traffic matrix.
See the README's Limitations section.

## Releasing

1. Bump `version` in `pyproject.toml` and `CITATION.cff`; add a
   `CHANGELOG.md` entry.
2. Run the tests; `python -m build`; `python -m twine check dist/*`.
3. Tag `vX.Y.Z` on `main` and push the tag; upload to TestPyPI, then PyPI.
